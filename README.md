# λάβρυς · Labrys · 拉布里斯

**第一版 · v0.1.0 · MIT**

家庭多 Agent 网关，带跨平台工具箱与 IDE 收纳组件。可运行的 TypeScript 后端。一个家庭、一个所有者、多个有独立身份的成员。

用户说“κόραξ惹我生气了，就让雾岛纪来”，网关切换当前房间的接话成员，把原话与交接事件保存下来。雾岛纪能看到换人原因和房间里的对话；κόραξ回来时仍能看到自己的换人记录。各成员的私密记忆保留权限。

本版独立实现，使用内置 SQLite，无外部数据库服务。运行时无第三方 npm 依赖；使用 Node.js 自带 SQLite 和 TypeScript 类型擦除。需要 **Node.js 24.12+ 的 24.x 版本**。

## 运行

1. 将 `.env.example` 复制为 `.env`。
2. 填入 `GATEWAY_TOKEN`（至少 16 字符）。单模型可沿用 `MODEL_BASE_URL`、`MODEL_NAME` 和 `MODEL_API_KEY`；多模型可在启动后打开 `/models` 保存服务商、凭据与模型名单。
3. 在 `config.example.json` 编辑人设、别名和成员使用的模型。雾岛纪目前是明确标注的初始模板，待补用户自己的设定。
4. 执行 `npm start`，无需先安装依赖。默认监听 `127.0.0.1:8787`。

```bash
npm start
```

聊天客户端填写：

| 项目 | 值 |
| --- | --- |
| 协议 | OpenAI Chat Completions |
| Base URL | `http://127.0.0.1:8787/v1` |
| API Key | `.env` 中的 `GATEWAY_TOKEN` |
| 模型 ID | `family` |
| 可选请求头 | `X-Client-Id: phone`，仅用于来源标注与工具续轮绑定 |
| 可选房间头 | `X-Room-Id: family` |

同一网关、同一房间的不同客户端共享服务端原文历史和接话成员状态。`X-Client-Id` 是标签，不是独立身份凭证。本版所有认证客户端都代表同一家庭所有者，拥有管理权限；不适用于把同一 Key 分给不同权限的人。

```bash
curl http://127.0.0.1:8787/v1/chat/completions \
  -H "Authorization: Bearer $GATEWAY_TOKEN" \
  -H 'Content-Type: application/json' \
  -H 'X-Client-Id: phone' \
  -d '{"model":"family","messages":[{"role":"user","content":"κόραξ惹我生气了，就让雾岛纪来。"}],"stream":true}'
```

示例中的 `$GATEWAY_TOKEN` 需要在当前终端设置；Node 读取 `.env` 不会修改父终端的环境变量。

## 家庭记忆的约定

- 记忆所有者、原始说话者和当前接话者分别保存。模型输出中的名字不能改变身份权限。
- 原话属于事件记录。记忆是附有来源、作者、状态的陈述；成员可以对同一事件持不同观点。
- 私密工具结果也有可见性，避免它们通过下一轮共享聊天历史泄露给其他成员。
- 总控生成的换人事件是操作记录。它没有以某个 agent 的口吻写入个人或共享记忆。
- 共享记忆先按房间权限过滤，再检索。成员私人房间中的来源不能直接扩散到更多成员可见的共享记忆。
- 模型最终公开说出的内容会成为当前房间的公开对话。存储权限不是模型输出语义的自动脱密审核。
- 当前上下文装配使用最近的完整用户轮组，不截断原文、不拆散工具组；窗口外原话保留在数据库，按当前问题自动召回，也可用工具补查、展开和分页回读。字符预算不是精确 token 计数。

## 管理 API

以下接口都需要 `Authorization: Bearer <GATEWAY_TOKEN>`。默认房间 `family`，可用 `X-Room-Id` 或 `?room=` 指定。

| 方法 | 路径 | 内容 |
| --- | --- | --- |
| GET | `/health` | 进程健康；不验证真实模型能回答 |
| GET | `/v1/models` | 模型入口 `family` |
| POST | `/v1/chat/completions` | 当前房间聊天、明确自然语言换人、工具续轮 |
| GET | `/api/model-routing?agent=korax` | 当前成员模型及脱敏配置 |
| POST | `/api/model-routing/config` | 保存服务商、模型名单与备用策略 |
| POST | `/api/model-routing/select` | 选择成员的模型路由 |
| GET | `/api/state` | 成员、房间与当前接话成员 |
| POST | `/api/recall` | 所有者按问题联合检索记忆与原文 |
| GET | `/api/memory-index` | 索引模式、完成状态与故障 |
| POST | `/api/memory-index/rebuild` | 后台重建派生索引，保留原文 |
| POST | `/api/memory-relations` | 带来源标记修订、纠正、限定或冲突 |
| GET | `/api/cache` | 缓存命中、失效、容量和上游命中 token；不返回缓存正文 |
| GET | `/api/history?limit=100` | 当前房间事件原文，最多 1000 条 |
| GET | `/api/memories?query=关键词` | 所有者查看当前房间记忆 |
| POST | `/api/memories` | 用户追加记忆；无来源时将用户便签单独记为来源 |
| POST | `/api/memories/:id/supplement` | 追加补充 |
| POST | `/api/memories/:id/challenge` | 追加异议 |
| POST | `/api/memories/:id/confirm` | 用户核实确认 |
| POST | `/api/rooms` | 创建房间及成员名单 |

共享事实示例：

```json
{"visibility":"shared","kind":"fact","text":"用户明确说自己喜欢喝醋。"}
```

私密记忆示例：

```json
{"visibility":"private","ownerId":"korax","kind":"observation","text":"这次用户因为我的回复生气了，需要先认真听清要求。"}
```

补充/质疑/确认请求体：`{"text":"操作理由","sources":["实际来源 ID"]}`。用户管理 API 可省略 sources，由用户便签留源；模型工具始终必须给实际来源。

创建房间：

```json
{"id":"studio","name":"工作室","members":["korax","kirishima"],"activeAgentId":"korax"}
```

## 当前边界与后续菜单

| 项目 | 进度 |
| --- | --- |
| 真模型接通 | 已实现 OpenAI 兼容上游；本次用本地模拟服务验证协议，未使用用户密钥做真实模型验收 |
| 任意复杂自然语言换人 | 当前覆盖明确句式；复杂、含糊、条件或引述表达保持现状；需继续扩展并验收 |
| 独立工作区与文件工具 | 已实现成员文件权限、逻辑路径、版本和明确分享；没有通用 shell/代码执行沙箱 |
| 社交系统 | 后台协作、任务交接和手机工作台已实现；成员间邮件、拜访、礼物和关系展示仍待实现 |
| QQ/OneBot 改名 | 文件/消息与 HTTP 入站适配已接；机器人名称自动同步仍未实现 |
| 服务端 MCP 执行 | 已接入 stdio / Streamable HTTP；npm 和 Python 真实本地安装验证、HTTP 本地协议验证；Docker 无实机验收 |
| MCP OAuth | 当前支持凭据引用注入，遇到 OAuth 服务返回需要授权；浏览器授权回调与令牌刷新尚未实现 |
| 多用户、多家庭 | 未实现；当前只服务一个家庭所有者 |
| 多供应商凭证配置 | 已实现 OpenAI 兼容多地址/独立凭据引用与成员模型选择；原生 Anthropic/Gemini 协议未接入 |
| 语义检索、异步记忆提炼 | 可选语义索引和模型提炼未实现；已实现本地 BM25/RRF、别名扩展、原文轮组、时间与修订关系 |
| token 精确预算 | 尚未实现；故障模型接替已实现，字符预算不保证任意模型窗口兼容 |
| 请求失败后的事务恢复 | 失败会留下原始输入与失败事件；自动重试可能新增输入，成功响应的幂等去重不覆盖所有失败窗口 |
| 工具回传幂等 | 严格校验一次匹配；失败重试的工具续轮还需后续增强 |

模型人设最终表现需要实际模型测试。共享原文与记忆状态已落盘，但每次发送给模型的内容受上下文预算限制，不承诺模型逐字回忆所有历史。

## 实现入口

- `src/commands.ts`：换人句式。
- `src/store.ts`：事件、房间、记忆与权限。

- `src/provider.ts`：OpenAI 兼容上游与 SSE。

- `src/server.ts`：HTTP 与管理 API。
- `src/mcp/`：后台部署、MCP 协议、凭据、作用域、日志和手机管理页。
- `src/world/`：后台执行、工作区、原生语音、跨端投递、平台接收、通知和手机工作台。
- `DESIGN.md`：家庭记忆和世界系统设计。
- `DESK.md`：日记、生活计划、工具箱和可扩展功能的行为与边界。
- `integrations/ide-toolbox.ts`：可挂载到 IDE 的顶部工具箱组件。
- `CACHE.md`：跨端缓存的实现和可验证边界。
- `MCP.md`：服务器安装与管理 MCP 的使用说明。
- `WORLD.md`：五项新能力与平台接入步骤。
- `channels.example.json`：平台、目的地和勿扰配置示例。
